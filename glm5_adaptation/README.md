# GLM-5 Adaptation

> Claude Cookbooks to GLM-5 Migration Examples

## 📚 Examples

1. **Basic Chat** (`basic_chat_glm5.py`)
   - Simple conversation
   - Model mapping
   - Response handling

2. **Tool Calling** (`tool_calling_glm5.py`)
   - Function calling
   - Multi-tool support
   - Adapter pattern

3. **Streaming** (`streaming_glm5.py`)
   - Real-time output
   - Callback support
   - Progress display

4. **Long Context** (`long_context_glm5.py`)
   - 128K tokens support
   - Smart chunking
   - Document QA

## 🚀 Quick Start

```bash
# Install dependencies
pip install zhipuai

# Set API key
export ZHIPUAI_API_KEY="your-key"

# Run example
python basic_chat_glm5.py
```
